Exclusão de Conta e Dados

OrquiDiário · CodeGarden Studio

Sobre esta página

Esta página explica como usuários do aplicativo OrquiDiário podem solicitar a exclusão da conta e de todos os dados associados, conforme exigido pela Google Play.

1. Quais dados são armazenados

O OrquiDiário armazena os seguintes dados de conta:

  • E-mail (obrigatório)
  • Senha (criptografada)
  • Nome (opcional)
  • Foto de perfil (opcional)

Além disso, o app armazena dados de uso, como:

  • Plantas cadastradas
  • Fotos das plantas
  • Anotações e registros de cultivo

2. Como solicitar a exclusão da conta

Para excluir sua conta e todos os dados associados, envie um e-mail para:

codegardenstudio@gmail.com

Inclua as seguintes informações:

  • Assunto: Exclusão de Conta — OrquiDiário
  • O e-mail utilizado na conta
  • Confirmação de que deseja excluir permanentemente sua conta

Após a solicitação, a exclusão será concluída em até 7 dias úteis.

3. O que é excluído

Ao excluir sua conta, os seguintes dados são removidos permanentemente:

  • Conta (e-mail e senha)
  • Nome e foto de perfil
  • Plantas cadastradas
  • Fotos das plantas
  • Anotações e registros

4. O que pode ser mantido

O OrquiDiário não mantém dados após a exclusão da conta. Nenhuma informação é enviada para servidores externos ou terceiros.

5. Exclusão local pelo usuário

Você também pode excluir seus dados diretamente no dispositivo:

  • Excluir plantas e fotos manualmente dentro do app
  • Desinstalar o aplicativo (remove todos os dados locais)

6. Contato

Para dúvidas sobre exclusão de dados ou privacidade:

E-mail: codegardenstudio@gmail.com
